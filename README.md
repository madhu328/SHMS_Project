# 🏥 Smart Hospital Management System (SHMS)

A full-stack web application built using **React.js** and **Node.js** to digitalize and automate hospital operations. SHMS provides a centralized dashboard, role-based access, real‑time workflows, and modules for OPD, ER, HR, Inventory, Rooms, and additional system features.

---

## 🚀 Key Features

### 🔹 SHMS Dashboard Portal (`/dashboard`)
Central hub showing analytics, alerts, patient flow, and shortcuts to all modules.

# 🏗 Technical Architecture

### 🎨 Frontend: **React.js**
- Component-based UI
- React Router navigation
- Redux / Context state management
- Responsive design with modern UI

### ⚙ Backend: **Node.js (Express.js)**
- RESTful API structure  
- JWT authentication  
- Middleware-driven architecture  
- Error handling + logging modules  

### 🗄 Database
- MongoDB or PostgreSQL supported  
- Supports large-scale medical record storage  

### ☁ Cloud Support
Deployable on:
- AWS  
- Azure  
- Render  
- Vercel (Frontend)
